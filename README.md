# NYC Filming Locations Map

Este es un mapa interactivo desarrollado en Python con **Streamlit** que muestra las localizaciones de rodaje en Nueva York basadas en el dataset del libro *Scenes from the City*.

## Características
- Visualización interactiva con marcadores.
- Filtrado por película.
- Enlaces directos a IMDB.
- Datos procesados desde un archivo XML de Excel.
